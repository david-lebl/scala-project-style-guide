# scala

A skill for writing Scala 3 backend code in functional, effect style with
[ZIO](https://zio.dev): coding style and tooling, pure functional principles,
effect fundamentals, the error model, resources and concurrency, and a
hexagonal / Domain-Driven Design architecture where each bounded context is a
two-module (`*-core` / `*-infra`) hexagon.

The chapters are the self-contained, agent-oriented form of this repository's
style guide (`guides/`, `decisions/`, `examples/`).

## Prerequisites

This skill assumes sbt 1.x, Scala 3 and ZIO 2.
